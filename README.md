### Leetcode入门和常见的算法套路

#### 课程目标

学完本课程，就可以达到能看懂各种题解的程度。因为能看懂题解，所以就可以独立刷题了。虽然可能还是难以自信白板编码，但是已经具备自我迭代、自我练习进步的能力。

#### 学习前提条件

Python基础素养

#### 选题思想

LeetCode 算法是有套路的，只要掌握了套路就可以迁移到其他的题目上，省下很多功夫。每开一个专题，应该专注于把本专题的重要套路讲解完毕（除非认知负担重的时候，此时中间可以停下来练一两道题），然后就可以开新的专题了。按照这个思想，作为一个零基础入门速成课程已经足够。
